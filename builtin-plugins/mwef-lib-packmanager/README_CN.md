# mwef-lib-packmanager

MWEF 内置在线插件管理器。页面入口为“扩展设置 → 插件管理”。

## 功能

- 从 MWEF Index Schema v1 软件源读取在线插件。
- 按全部、可更新、可安装和已安装状态筛选，并支持本地搜索。
- 在线包下载后强制核对索引声明的精确字节数和 SHA-256。
- 继续复用框架的安全路径检查、解包检查、权限确认、事务安装、升级备份和失败回滚。
- 使用小米 WebUI 风格弹窗设置插件列表地址和 GitHub 镜像/代理前缀。
- 默认提供 GitHub Raw、jsDelivr 索引和 `ghfast.top` GitHub 下载代理预设，也可填写自定义 HTTPS 地址。

## 持久化配置

软件源设置写入：

```text
/data/other_vol/xqext/config/mwef-lib-packmanager/sources.json
```

配置位于框架 `config` 目录，因此插件升级和框架在线更新会保留设置。

## 安全说明

浏览器只向服务器提交插件 ID；归档 URL、大小和 SHA-256 均由路由器从已验证的索引记录中选取。下载完成后，待安装包的 ID、版本、作者、兼容要求和权限还会与索引再次比对。

当前路由器网络兼容模式与框架更新器一致，使用 `curl -k`。SHA-256 能发现镜像内容与当前索引不一致，但未签名索引无法抵御同时替换索引和归档的主动中间人攻击。请仅在可信网络中使用可信软件源。
